# Instructions for the coding agent

## Project
AutoTest Agent: a Python CLI that generates, runs, and repairs pytest tests. Read PLAN.md first.

## Rules
- Python 3.11+. Follow the structure in PLAN.md. Keep modules small and readable.
- Never write API keys or tokens in code or files. Read them from environment variables (.env, git-ignored).
- Run code generated by the tool only inside the `workdir/` folder, never in the user's repo.
- Add or update tests in `tests/` for every module you write, and run `pytest` before saying a task is done.
- Do not add dependencies without telling me; list them in requirements.txt.
- Explain what you changed in plain language after each task so the team can understand every line.
- If you are unsure about a requirement, ask instead of guessing.

## How to run
- Tests: `pytest`
- CLI: `python -m autotest ./repo --module file.py`
